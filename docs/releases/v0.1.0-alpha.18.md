# sealr 0.1.0-alpha.18

Alpha.18 admits minimal GNU tar records and keeps archive-bomb rejection strict.
Real bombs still fail `quota.ratio`. The default `max_ratio` stays 100.

## Minimal GNU tar records

GNU tar writes 10240-byte records. Derived TAR compression ratios no longer
charge the mandatory 1024-byte terminator or the all-zero bytes that finish the
single record containing that terminator. Only that one record is excluded from
the numerator. Member payloads, headers, per-member block padding, and trailing
zeros past that record stay charged.

`ratio_exceeds` remains a strict greater-than comparison. At `max_ratio` 100,
1000/10 and 100/1 pass, and 1001/10 and 101/1 still exceed. A terminator that
is not exactly 1024 bytes, or that is not adjacent to the trailing-zero range,
charges the full decoded length.

Member names may start with `./`. That prefix is normalized away, including an
archive-root directory from `tar -C dir .`. Absolute paths, `..`, embedded dot
components, and links stay rejected.

`format.unsupported` and `tar.dialect` findings carry a hint naming the observed
signature and the `--format` values whose profiles start with it. The hint is
not used to select an interpretation.

## Other preview behavior in this source tree

Unix symlink ZIP entries are reported as `zip.symlink`. On a terminal, with
neither `--view`, `--receipt`, nor `--json`, the CLI prints a one-line summary
on stderr. Redirected output stays JSON. `--json` forces the view and receipt
JSON on a terminal.

Alpha.17 remains the published native distribution: typed publisher outcomes,
tested evidence and Rust consumer migrations, named durability controls, and
reproducible assurance bookkeeping. This source tree does not yet have
Alpha.18 release artifacts. Authenticate the published archives with
[release verification](../release-verification.md). Do not substitute an older
companion for a future archive or infer checksums that have not been published.

This is a GitHub-only development preview, not a crates.io publication, stable
API freeze, independent security audit, or production-containment claim.

The [roadmap](../../ROADMAP.md) still prioritizes measuring time spent in
source hashing, plan validation, worker setup, and payload work before a runtime
performance change, followed by lifecycle and coordinated dependency work.
Historical Alpha.15 read measurements retain their original provenance and
are not an Alpha.18 performance claim.
